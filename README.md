# Usage Tracker

A native macOS 26+ menu-bar app that shows AI usage and spend across Cursor,
Anthropic, and OpenAI in one place.

## Status

Early development. Nothing to install yet.

## Planned

- Cursor billing-cycle usage and pacing.
- Anthropic usage and cost.
- OpenAI usage and cost.
- Credentials stored only in Keychain.
- Periodic refresh that pauses while the Mac is asleep or offline.
