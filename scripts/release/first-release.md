Usage Tracker is a native macOS menu-bar app that shows your AI usage and spend for Cursor, Anthropic and OpenAI in one place. Each configured provider gets its own menu bar item with its current usage, spend and pacing; a provider you haven't set up shows nothing, and one that fails doesn't hold up the others.

Credentials you paste in are stored only in the login Keychain, and are never logged or shown in full.

Install it with Homebrew: brew install --cask MMSs/tap/usage-tracker. It requires macOS 26 on Apple Silicon, and it updates itself from then on.
